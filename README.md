# slides

発表スライドの公開場所。<https://kennyfujita.github.io/slides/private/>

パスワードを知っている人だけが読める。**タイトルも鍵の内側にある。**
入口ページ自体が暗号文で、解錠すると一覧が現れる。配信される HTML に題名は
一切書かれておらず、ファイル名も内容を示唆しない文字列にしてある。

```
private/index.html   入口。解錠すると一覧が現れる
<12桁hex>.html       各スライド。中身は暗号文
```

パスワードは1回でよい。入口で入れたものを `sessionStorage` で引き継ぐ。

## 仕組み

| 段階 | 使うもの |
|---|---|
| 鍵導出 | PBKDF2-HMAC-SHA256、200,000 回、salt 16 バイト、512 bit |
| 暗号化 | AES-256-CBC（前半 256 bit を鍵に使う） |
| 改ざん・パスワード判定 | HMAC-SHA256（後半 256 bit）で encrypt-then-MAC |
| 本文 | 暗号化の前に gzip する |

ブラウザ側は [`assets/gate.js`](assets/gate.js) が Web Crypto API で同じ手順を逆に辿る。

保存は解錠後の一覧の各行と、スライド右下の2か所から取れる。**どちらも落ちるのは
平文のスライド**で、開くのにパスワードは要らない。ボタン自身を取り除いてから
Blob にするので、落ちたファイルを開いても保存ボタンは出ない。外部読み込みを
持たないのでオフラインで開く。

## 承知しておくこと

**これは「不意に見られたくない」ものを置く場所であって、秘密を守る仕組みではない。**
暗号文は誰でもダウンロードでき、手元で好きなだけパスワードを試せる（オフライン総当たり）。
PBKDF2 20 万回はその速度を落とすだけ。

- 他のサービスと同じパスワードを使わない
- 名前や誕生日を含むパスワードにしない
- 本当に外に出せないものはここに置かない

## 更新のしかた

タイトルと平文の場所は `decks.json` にだけ書く（`.gitignore` 済み）。
書き方と、公開リポジトリで守るべき決まりごとは [`CLAUDE.md`](CLAUDE.md) にある。

```sh
SLIDES_PASSWORD='...' python3 build.py
git add -A && git commit -m "..." && git push
```
